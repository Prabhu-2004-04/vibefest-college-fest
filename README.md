# VibeFest — College Fest Landing Page (Project 06)

A responsive college festival landing page concept made with HTML, CSS, and vanilla JavaScript. This is a fictional frontend practice project, not an official event website.

## Features
- Bold festival poster-inspired hero section
- Event category cards for music, dance, creative arts, and gaming
- Interactive two-day schedule switcher
- About section, registration form demo, and FAQ accordion
- Responsive navigation for mobile screens
- Responsive layouts for phone, tablet, and desktop

## Run locally
1. Extract this project folder.
2. Open `index.html` in VS Code.
3. Use Live Server, or open `index.html` in a browser.

## Deploy on GitHub Pages
1. Create a repository named `vibefest`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Once deployed, copy the published URL into the repository description.
